# Sikrets

Credential brokering by Tennant: steal every stored key, they still won't work.

Sikrets holds your real API keys and only lends their power to workloads that prove they're your authorized application. This repo is currently the marketing site at **sikrets.usetennant.com**; the product itself isn't built yet.

```bash
bun install
bun dev
```

Deployed on Vercel (`munachiernests-projects` team, which owns `usetennant.com`).
